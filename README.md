# MyLang

MyLang is a beginner-friendly interpreted programming language inspired by QBASIC.

## Features

- Variables
- Strings
- Numbers
- Math
- Input
- IF / ELSE
- Repeat loops
- While loops
- Functions
- Parameters
- Return values
- Arrays
- Built-in standard library
- REPL
- Error handling

## Run Script

```bash
python main.py
```

## Run REPL

```bash
python repl.py
```
