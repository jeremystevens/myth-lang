## 🌌 &nbsp; What is MYTH Lang?

</div>

MYTH Lang is a **lightweight scripting language** designed to feel simple, clean, and approachable — while staying powerful enough for real projects.

Inspired by retro computing environments and modern developer workflows, MYTH Lang combines the joy of classic BASIC-era programming with a full-featured modern IDE, a rich standard library, and a tightly integrated runtime.

<br>

<div align="center">

|  | Core Principle | What It Means |
|:---:|:---|:---|
| 🎨 | **Creative First** | Programming should feel like making something, not solving a corporate ticket |
| 📖 | **Readable Syntax** | Code you write on Monday should still make sense on Friday |
| ⚡ | **Instant Execution** | Go from idea to running output in seconds — no build steps, no config |
| 🌱 | **Beginner Friendly** | No gatekeeping, no steep learning curves, no hidden complexity |
| 🕹️ | **Retro Meets Modern** | Classic aesthetics with autocomplete, debuggers, and package managers |
| 🔓 | **Open Source** | Built in public, shaped by the community |

</div>

## 🚀 &nbsp; Quick Start

</div>

```bash
# Clone the repository
git clone https://github.com/your-username/myth-lang.git
cd myth-lang

# Install the IDE dependency
pip install PySide6

# Launch the IDE
python ide.py

# Or run a script directly from the command line
python main.py examples/hello.my
```

> **No configuration files. No build steps. No boilerplate.**
> Write a `.my` file, press <kbd>F5</kbd>, see your output.

### IDE Features at a Glance

<details>
<summary><strong>🎨 Three Themes</strong></summary>

<br>

| Theme | Feel | Colors |

| **Dark** | Deep navy with blue accents | Catppuccin-inspired, easy on the eyes |

Switch themes instantly from the toolbar dropdown — every panel, dock, and scrollbar updates immediately.

</details>

<details>
<summary><strong>🔴 Integrated Debugger</strong></summary>

<br>

- **Click the line-number gutter** to set a red breakpoint dot
- Press <kbd>F7</kbd> to start a debug session
- The green **▶** arrow shows the current execution line
- **Variable Inspector** — live snapshot of all variables at each pause
- **Call Stack** — full function frame hierarchy with parameter values
- **Exception Viewer** — formatted runtime errors with source line context
- Step with <kbd>F10</kbd>, continue with <kbd>F5</kbd>, stop with <kbd>F6</kbd>

</details>

<details>
<summary><strong>🧠 Live Language Services</strong></summary>

<br>

- **Live analysis** runs 400ms after every keystroke — no manual trigger
- **Red squiggly underlines** on syntax error lines
- **Autocomplete popup** — keywords, 40+ builtins, your own functions and variables
- **Function hint bar** — shows signature with current argument highlighted
- **Token Viewer** — every token from the lexer, colour-coded by type
