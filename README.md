# MYTH Lang

> A retro-futuristic open-source programming language and IDE focused on simplicity, creativity, productivity, and rapid scripting.

---

# What is MYTH Lang?

MYTH Lang is a lightweight scripting language designed to feel simple, clean, and approachable while still being powerful enough for real projects.

Inspired by retro computing environments and modern developer workflows, MYTH Lang aims to combine:

- Easy-to-read syntax
- Fast scripting workflows
- A custom retro-inspired IDE
- Productivity-focused tools
- A fun and creative programming experience

Whether you're learning programming, building tools, automating tasks, or experimenting with ideas, MYTH Lang is built to stay approachable without feeling limiting.

---

# Philosophy

MYTH Lang is built around a few core ideas:

- Programming should feel creative
- Syntax should stay readable
- Development environments should feel inspiring
- Rapid experimentation should be easy
- Beginners should feel welcome
- Retro aesthetics and modern workflows can coexist

---

# Features

- Simple beginner-friendly syntax

- Open source and community driven
